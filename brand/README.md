# Typing Force brand kit

## Identity

Make every key count. A typing practice brand built around control, momentum, and earned progress. Calm and precise in use; confident and energetic in campaign graphics. Ryan requested a normal keyboard, so use conventional keyboard imagery rather than sculptural or surreal hardware.

## Visual assets

- Original campaign image: typing-force-keyboard.png, created with OpenAI image generation for this project.
- Web artwork: ../public/brand/typing-force-keyboard.webp.
- Social cover: ../public/brand/typing-force-social.jpg, 1200 × 630.
- Vector insignia: ../public/brand/mark.svg.
- Vector wordmark: ../public/brand/wordmark.svg.

The insignia combines three forward-moving rails with an F. Use it on a forest background, with generous clear space. Keep the artwork outside the typing passage. Never animate decorative graphics while someone is typing.

## Palette and type

Forest #103c2d, chartreuse #d4ed43, ivory #f3f5e9. Chartreuse is an identity accent, not small text on light surfaces. Interface tokens use accessible theme-specific colors in src/practice.css.

DM Sans for interface copy; IBM Plex Mono for typing and measurement. Both are self-hosted. The campaign wordmark can use a heavier condensed treatment; keep interface labels familiar and readable.

## Voice

Direct, encouraging, specific. Practice, precision, progress. Celebrate measured improvement; avoid invented benchmarks, psychological labels, and pressure to compete.
